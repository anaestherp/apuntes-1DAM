
## ¿Qué es un programa informático?

Un programa informático es un conjunto de instrucciones escritas en un lenguaje de programación que un ordenador puede ejecutar para realizar una tarea específica. Estas instrucciones indican al sistema cómo procesar datos, interactuar con el usuario y producir resultados.

## Diferencia entre código fuente, código objeto y código ejecutable

### Código fuente
Es el texto escrito por el programador en un lenguaje de programación (como C, Java o Python). Es legible para las personas y puede modificarse fácilmente.

### Código objeto
Es el resultado de compilar el código fuente. Contiene instrucciones traducidas parcialmente al lenguaje máquina, pero aún no está listo para ejecutarse de forma independiente.

### Código ejecutable
Es el archivo final generado tras el proceso de compilación y enlazado. Puede ser ejecutado directamente por el sistema operativo.

| Tipo | Descripción | Legible por humanos |
|--------|-------------|-------------------|
| Código fuente | Programa escrito por el desarrollador | Sí |
| Código objeto | Resultado de la compilación | No |
| Código ejecutable | Programa listo para ejecutarse | No |
